Questions

Can my agent spend more than I allow?+

No. You set a total budget and a per-call cap. The price is checked before anything is signed, over-cap calls are refused with no transaction, and the budget holds across restarts and parallel calls.

What if a payment's outcome is unknown?+

It stays held: counted against your budget, never treated as free. You can check it on-chain later, or release it from Activity.

Will I pay twice for the same request?+

No. Repeating the same request returns the stored result instead of paying again.

Do I need XLM, API keys or a subscription?+

No. Your agent pays per call in USDC. There's no XLM to hold for fees, no keys to manage and no plan to sign up for.

Where do the tools come from?+

Toolport's own registry, plus Rail402's Bazaar, a third-party catalog we search and credit. One MCP connection covers both.

Is this real money?+

Not yet. Toolport runs on Stellar testnet with test USDC. Get some from the testnet faucet.
